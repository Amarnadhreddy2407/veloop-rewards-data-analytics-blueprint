This repository covers VELOOP Rewards — Data Analyst Internship Task 01 (Product Analytics, Data Readiness & Data Management Blueprint), a developing online rewards and engagement ecosystem where the focus is on designing reliable event tracking, lifecycle schemas, data quality rules, and data models for future production data rather than treating simulated test data as live company metrics. It includes completed blueprint work across Work Packages A through H in the project spreadsheet—covering product area mapping, user vs. system vs. business event distinctions, coverage and analytics gaps, core identifiers and user/account lifecycle fields, the five-stage earning and reward/failure model, wallet ledger and withdrawal lifecycles with withdrawal KPIs, the four-stage referral funnel and engagement metrics, a standardized 30-event tracking plan, a 78-field data dictionary, and a logical data model with relationship mappings—all marked Proposed where unverified, with the remaining work packages and final deliverables scheduled next.
